## Problem / Motivation

After reading the Stage 0 literature report, the owner set the project's real target on 2026-10-13:

- a local English and Turkish assistant for calendar, email and reminders;
- trained from scratch with volunteer compute;
- built under a strict data policy.

The owner also asked to stop spending laptop days on experiments that only test whether the concept works, and to build the networked system instead.

None of this was written down. `docs/PLAN.md` describes Stage 0 only, and the SRS outlines Stages 1 to 3 around the old premise.

## Implementation Approach

The roadmap records the plan discussed with the owner on 2026-10-13 and the four answers given that day:

- both work-unit kinds in network v1;
- a system study before choosing a framework;
- a small cloud server for the pilot coordinator;
- 3 to 5 trusted people for the pilot.

It keeps the old documents as records rather than rewriting them now. The SRS rewrite is its own step (1.4), so that it can draw on the system study and the product spec.
